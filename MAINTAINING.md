# Updating this website

| To do this | Edit this |
|---|---|
| Add news or a milestone | `_data/milestones.yml` |
| Add a talk, slides or photos | `_data/talks.yml` (files go in `files/talks/` and `images/talks/`) |
| Add a paper | new file in `_publications/` (copy an existing one) |
| Add a paper's video | set `youtube:` in that paper's file in `_publications/` |
| Show Videos or Wave Lab in the menu | uncomment them in `_data/navigation.yml` |
| Change your sidebar details | `author:` section of `_config.yml` |

Videos and Wave Lab also have `sitemap: false` in their page files. Remove that line when you show them.
